# Third-party assets

TuwaiqOS itself is MIT licensed (see `LICENSE`). This file records material
that originates elsewhere, so the provenance of every embedded artefact is
auditable.

## `kernel/src/font8x8.rs`

IBM VGA `font8x8_basic`, ASCII `0x20..=0x7E`, by Daniel Hepper.
**Public domain.** No obligations.

## `kernel/src/banner.rs`

A 1-bit-per-pixel raster of the boot tagline, produced by
`tools/gen_splash.py` from whichever font the build host provides. The
committed table was generated with **DejaVu Sans**, which carries the
Bitstream Vera licence:

> Copyright (c) 2003 by Bitstream, Inc. All Rights Reserved.
> Bitstream Vera is a trademark of Bitstream, Inc.
> DejaVu changes are in public domain.

Only a fixed-size bitmap of a single 29-character string is embedded — no font
program, no outlines, and nothing that could be reconstructed into a typeface.
Whether such a raster constitutes a copy of the Font Software is not settled
law; typeface *designs* are not copyrightable in the United States, and only
the font program itself is. This notice records the origin so the question is
visible rather than silently assumed.

`tools/gen_splash.py` takes `--font`, so the tagline can be regenerated from
any face. If the project prefers an unambiguous position, an SIL Open Font
Licence face such as **Amiri** or **IBM Plex Sans** would remove the question
entirely and only requires re-running the generator.
